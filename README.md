# VedaAI Assessment Creator

## Overview
Monorepo scaffold for the VedaAI Assessment Creator with a Next.js frontend and an Express TypeScript backend.

## Repo Structure
- `frontend/` - Next.js app (TypeScript, App Router, Tailwind)
- `backend/` - Express API scaffold (TypeScript)

## Getting Started
Frontend:
```bash
cd frontend
npm run dev
```

Backend:
```bash
cd backend
npm run dev
```
